The current application starts directly at the Cart page, which does not accurately demonstrate the complete user journey.

I want to transform this into a realistic Blinkit-inspired shopping application that showcases my AI-powered feature, "Blinkit Smart Discovery," in its natural context.

The objective is NOT to recreate the entire Blinkit application but to build a polished MVP that demonstrates how AI can increase cross-category purchases.

=========================================================
PROJECT GOAL
=========================================================

Build a complete end-to-end shopping experience where users naturally discover the AI recommendation during checkout.

The Smart Discovery recommendation should be the centerpiece of the application.

6. ⭐ AI Smart Discovery (Core MVP)

This is the most important screen.

When the user clicks "Proceed to Checkout", the backend should:

• Analyze purchase history
• Analyze current cart
• Identify shopping intent
• Calculate exploration score
• Detect categories the user has never explored
• Recommend ONE product from a NEW category

=========================================================
DATA SOURCES
=========================================================

Use

• Real Blinkit Product Catalog (public product information)

• Synthetic Customer Profiles

• Synthetic Purchase History

• Synthetic Current Cart

The application should use these datasets dynamically rather than hardcoding data.

=========================================================
AI RECOMMENDATION ENGINE
=========================================================

The recommendation engine should:

1. Load customer profile

2. Load purchase history

3. Load current cart

4. Detect shopping mission

5. Calculate exploration score

6. Identify unexplored categories

7. Retrieve products from those categories

8. Ask the LLM to generate:

   • Best recommendation

   • Reason for recommendation

   • Confidence score

9. Return a structured JSON response.
